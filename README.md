# AI Content Marketing using UGC Ads

## Project Overview

This project focuses on using Artificial Intelligence to create User-Generated Content (UGC) style advertisements for a local business.

The selected business is **Divine Cuisine**, a home-based cloud kitchen located in Mangalore, Karnataka.

The project uses AI-powered content generation to create authentic, relatable and conversion-focused advertisements suitable for social media platforms.

## Business Details

**Business Name:** Divine Cuisine

**Business Type:** Cloud Kitchen

**Location:** Mangalore, Karnataka

**Tagline:** Homely Food, Divine Bite

## Campaign

**Campaign Name:** Divine Cuisine UGC Advertising Campaign

**Main Product:** Homemade Lunch & Dinner Meals

## Target Audience

- College students
- Working professionals
- Office employees
- Families
- People looking for convenient homemade-style food

## Objective

The objective of this project is to use AI to create engaging UGC-style advertising content that feels natural and authentic rather than like a traditional advertisement.

The campaign focuses on:

- Creating attention-grabbing hooks
- Writing short-form UGC ad scripts
- Creating problem-solution advertisements
- Generating strong calls-to-action
- Creating social-media captions
- Developing short-form video concepts
- Adapting content for different platforms
